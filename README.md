# Attariya Hospital — Premium Frontend Prototype

Ready-to-open multi-page static frontend with responsive navigation, department and doctor directories, profile and service details, patient contact pages, information sections, and a draft-email appointment form.

## Run
- Open `index.html` in a modern browser.
- Recommended: `python -m http.server 8000` in this folder, then open http://localhost:8000.
- Upload these files to a static host to preview.

## Important
- **Demo only**: appointment/contact forms open a visitor-side mail app; they do not submit or save information.
- The blue/red logo and cover were provided by the project requester.
- The doctor names come from the original reference website; their current affiliations are not confirmed.
- Unsplash photographs are illustrative, not hospital premises or actual staff. Use approved real photographs for production.
- A few additional service/department page categories represent the original doctors' listed specialties; not a verified current catalog.
- Original source and verification notes are in `content-sources.md`.
- Hospital needs to verify all information and legally review the privacy policy before release.
